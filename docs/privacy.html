MyFolio — Chrome Extension

Privacy Policy

Operator: JJJJJ Enterprises, LLC  ·  Last updated: May 27, 2026

Plain-language summary: MyFolio collects no data about you. There is no MyFolio server, no backend, no analytics, and no telemetry. Your financial information is read from your browser's existing session, processed locally, and never leaves your device. The only outbound request the extension makes is fetching public ETF price data for benchmarks — which sends only a ticker symbol and date range, nothing personal.

1. What MyFolio Is

MyFolio is a personal-use Chrome browser extension that overlays a modern dashboard on top of your LPL AccountView brokerage account. It was built by an individual developer for their own use and shared freely. There is no MyFolio server, no MyFolio user account system, no MyFolio database, and no MyFolio analytics pipeline. JJJJJ Enterprises, LLC has no way to see your data because there is nowhere for it to go.

2. Data MyFolio Does NOT Collect

MyFolio does not collect, transmit, store on any external server, log, sell, or share any of the following:

  • Your name, email address, phone number, postal address, Social Security number, or any personal identifier
  • Your brokerage username, password, MFA codes, session cookies, or any authentication credential
  • Your account numbers, balances, holdings, transactions, returns, or any financial data — these are processed locally only (see Section 3)
  • Your IP address, browser fingerprint, device identifier, or operating system
  • Your location, time zone, or any geographic data
  • Usage statistics, click events, scroll behavior, or keystroke patterns
  • Error reports, crash logs, or any debug telemetry transmitted to any server
  • Anything at all via cookies — the extension sets no cookies

MyFolio does not sell, rent, share, or transfer any data to any third party, advertiser, data broker, or analytics provider. It does not use your data to train or improve any AI/ML model.

3. What MyFolio Reads (In Your Browser Only)

While you are logged in to LPL AccountView, MyFolio reads the following data from the JSON API responses your browser is already receiving from the brokerage. MyFolio does not make any new requests to the brokerage's servers — it only reads responses the brokerage's own page has already requested.

Data Used For Leaves Your Device?
Account names, numbers, types, balances, day changes Displayed in the Overview tab NO
Holdings: symbols, quantities, prices, gain/loss Displayed in the Holdings tab NO
Transaction history: dates, types, amounts, quantities Displayed in the Transactions and Activity tabs; used to reconstruct chart history for recently-opened accounts NO
Portfolio daily value history Displayed in the Overview and Performance charts NO
Period returns (YTD, 1Y, 3Y, 5Y) Displayed in the Performance tab NO

4. What MyFolio Stores Locally

MyFolio stores data in your browser's chrome.storage.local so the dashboard can restore quickly on your next visit. This data is stored only on your device, encrypted at rest by Chrome, and is never transmitted anywhere.

Stored Item What It Contains How Long
Selected benchmark tickers Which ETFs you have ticked (e.g. ["spy","vti"]) Until you change them or uninstall
Load time samples Millisecond integers — no account data Until uninstall
Benchmark price history Public ETF closing prices from Stooq / Yahoo Finance 24 hours, then refreshed
Portfolio daily value history Date + total portfolio value pairs for chart display 24 hours, then refreshed
Per-account daily value history Date + per-account value pairs 24 hours, then refreshed
Cached transaction / activity history Dates, types, symbols, amounts — used for chart reconstruction Until uninstall or schema upgrade
LPL account identifiers Account IDs as returned by the brokerage's API 24 hours, then refreshed
Saved API endpoint metadata URL and HTTP method for value-over-time and activity endpoints (no response data) Until schema upgrade

None of this is accessible to JJJJJ Enterprises, LLC or any third party. To remove everything, uninstall the extension.

5. The Only Outbound Request MyFolio Makes

When you have at least one benchmark selected on the Performance tab, MyFolio fetches public ETF price history to draw the comparison chart. This is the only network request MyFolio initiates on its own.

Primary: Stooq

GET https://stooq.com/q/d/l/?s={ticker}.us&d1={start}&d2={end}&i=d

Sends only a ticker symbol (e.g. spy) and a date range. Returns public closing prices. Cached for 24 hours per ticker. No personal information is sent.

Automatic Fallback: Yahoo Finance

If Stooq is unreachable, MyFolio retries using query1.finance.yahoo.com (or query2). Same rule: only ticker symbol and date range are sent, no personal information.

As with any HTTP request, the receiving server sees your IP address as the network source. We do not control what these services log. If you do not want these requests made, deselect all benchmarks on the Performance tab — no benchmarks selected means no outbound requests.
